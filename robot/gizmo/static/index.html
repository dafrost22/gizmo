        Personalities

          A personality is a system prompt, a voice and its own tools. Switching takes a couple of seconds.

          System prompt

          Who it is and what it's for. It's the first thing the model reads, every turn.

          The whole prompt the model gets

          Yours, then how Gizmo works (gestures, tools, writing for the ear), which isn't editable so an edit can't break the robot. The list of skills is added when the session starts.

                        Sound clips
                        
            Short recordings it can play by itself: a catchphrase, a sound effect. Use WAV files, and only recordings you have the right to use.
